ヘリde破壊 v3 (大規模アップデート)

■ 世界
- 無限に生成される地形・湖・森・畑・街(飛行するほど新しいチャンクが生成、遠景は水平線まで)。上昇限度1500m
- 「大空・自由飛行」ステージ(燃料無制限、近づいた建物は破壊可能)を追加
- 都市/オフィス街は東京風の超高密度に。周囲にも都市が広がる
- 空・雲(立体的な雲層)・太陽・月・星のシェーダー。出撃前に時間帯(早朝〜深夜、0〜24時)を選択可能

■ 機体・街
- ヘリ/戦闘機/旅客機を、箱の組み合わせから滑らかなロフト形状+翼型断面+旋盤加工パーツに作り直し
- ビルに柱型・階帯・コーニス・バルコニー・日よけ・看板・屋上設備、倒壊後のがれき
- 車を6車種の滑らかなモデルに。信号待ちなしの大都市級の交通量
- 飛行場の旅客機が建物にめり込む問題を修正(自動で干渉を避けて配置)

■ 破壊
- 命中位置・威力に応じて外壁に燃える穴が開き、倒壊は最上階から崩れ落ちる(粉塵・破片・煙)
- 爆発はノイズ質感の火球・煙柱・衝撃波・火花・燃え残る炎に刷新

■ 操作
- キー割り当て自由変更、ジョイスティック(Thrustmaster等)対応(軸/ボタン割当・校正・ホバー位置設定)
- スロットルレバー=コレクティブ(上昇/下降)、別軸/PageUp・PageDownでスロットル(出力・前進速度)
- 飛行モデル: アーケード / シミュレーター(反トルク・翼面荷重・地面効果・並進揚力)
- 視点切替(V)、フレア(R)、ポーズ/設定(Esc)、フライトHUD(方位・速度・高度・水平儀・レーダー)

■ 音
- 送付いただいた効果音(機関銃・ミサイル・爆発×2・ヘリ・戦闘機・サイレン)をsfx/に収録して使用
- 位置に応じた定位・距離減衰・ドップラー・都市リバーブ

■ その他
- 燃料を150秒に延長(給油+60秒)
- 描画: HDRブルーム/MSAA/色空間修正/トーンマッピング、画質自動調整

【配置】index.html / game.js / three.min.js / config.js / ranking.js / sfx/ を公開フォルダへ置き換え

■ v3.1 追加
- ビルの構造破壊: 柱の損傷から崩壊を判定。支えを失うと上部が倒れる(転倒)/真下に潰れる(パンケーキ)/ずれ落ちて止まる、を物理的に再現。軽い損傷では倒れない
- シェーダー強化: 実際の空と連動する環境反射、窓ガラスの光沢、高さ・距離で変わる大気(空気遠近)、太陽の光線(ゴッドレイ)、地形の微細な凹凸
- ヘリ: 塗装テクスチャ+法線マップ(パネルライン・リベット・ステンシル・汚れ)、パイロット、照準に連動するターレット、3Dコクピット視点(計器・操縦桿・コレクティブが動く)、低空の吹き下ろしによる土煙・水しぶき
