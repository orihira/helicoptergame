# ヘリde破壊 v4 — 変更点

v3（`heridehakai_v3.zip`）からの変更をまとめました。フォルダ名は `heridehakai/` のまま、ランキング連携（`config.js` / `ranking.js`）は触っていません。`index.html` をブラウザで開くだけで遊べます。

## 1. 無限に続くリアルな街（マイクラ方式のチャンク生成）

- 中心ステージ（±150m）の外側に、**44mブロック単位で街を自動生成し続ける**ようになりました。プレイヤーの周囲にだけ建物を出し、離れると消すので、どこまで飛んでも街が続きます。同じブロックは毎回同じ見た目になります（決定的なハッシュ）。
- 中心から 150〜520m は**東京の高層オフィス街のような高密度コア**（26〜58mのタワーがほとんどのブロックに立つ）。その外は郊外、さらに遠くは従来のプロシージャルな町並みにつながります。
- 外側のビルも**壊せます**（中心ステージの破壊率には数えません）。屋根の設備・瓦礫つき。
- 敵ヘリ・敵戦闘機が街の外まで追ってくるようになりました（v3では±190mの壁に阻まれていました）。
- 街の外の地面を平らに均したので、空港の滑走路や基地が地形にめり込むこともなくなりました。

## 2. 空港の修正

- ホテルと運用棟が 0.5m 重なっていたのを修正（運用棟を移動・縮小）。
- 旅客機の駐機位置を広げました（翼端が隣の機体やターミナルに被らない間隔に）。
- 戦闘機基地の格納庫・管制塔を滑走路から後ろへ下げました。
- 全ステージに**建物の重なり自動チェック**を入れました。重なりがあるとブラウザのコンソールに `v4 overlap:` と出ます。v4では全7ステージで重なりゼロを確認済みです（都市のガソリンスタンド、高速道路の料金所、オフィス街の隣接ビルも修正）。

## 3. 交通量と車

- 都市ステージの走行車両を 7台 → **約20台**に（全ての大通りを走る）。オフィス街も約16台に。
- 街の外側にも**約14台の車**が道路グリッドを走り続けます。
- 車の速度・車種（トラック含む）にバラつきを出しました。

## 4. 操縦・物理（実機の考え方）

ヘリの操縦は実機と同じ4つの操作に整理しました（詳しくはゲーム内の「操作」説明・設定画面の飛行モデル欄にも書いてあります）。

- **コレクティブ**（全ブレードのピッチ＝揚力）：`Space`で上げる／`Shift`で下げる。上げると上昇する。タッチは ▲▼ ボタン。**フライトスティックのスロットルレバーもコレクティブとして使えます**（下記）。
- **スロットル**（エンジン出力＝ローターRPM）：`PageUp`で上げる／`PageDown`で下げる。上げると最大速度・加速が上がり、RPMが上がります。**スロットルを上げた状態で前に倒すと、より速く前進します**。
- **サイクリック**（機体の傾き＝進行方向）：`WASD`／スティック。速度がつくと**並進揚力**で同じコレクティブでも高度を保ちやすくなります。
- **ペダル**（機首の向き・トルク打ち消し）：`Q`／`E`。コレクティブを上げるほどトルクが増え、機首が流されやすくなります。
- **ローターRPMの低下**：コレクティブを上げすぎるとRPMが下がり、揚力が落ちます（スロットルで補う）。RPMが72%を下回るとHUDが赤く警告します。急降下からの急な引き起こしでは渦輪状態（VRS）の警告が出ます。
- 飛行モデルは設定で「アーケード／シミュレーター」を選べます。初期設定はシミュレーターです。

### フライトスティックのスロットルが効かなかった件（v3のバグ）

v3ではスティックの「上昇」軸を**瞬間的な入力**として扱っていたため、スロットルレバー（位置で決まる軸）を割り当てても、中央では何も起きず、倒しっぱなしだと上昇し続ける、という動きになっていました。v4では**レバーの位置そのものがコレクティブ（0〜100%）になる絶対軸**として読みます。

- 設定 → ジョイスティック → **スロットル軸**にレバーの軸番号を割り当ててください（軸番号はスティックを動かすと表示が変わるので分かります）。
- 割り当て後、レバーを手前に引く＝コレクティブ小（下降）、前に押す＝コレクティブ大（上昇）です。向きが逆なら「反転」をオンにしてください。
- モードは「絶対（レバー位置）」が既定です。レバーの代わりにバネ付きのスティック軸を使いたい場合は「相対（速度）」に切り替えてください。
- キーボードの `PageUp`／`PageDown`（スロットル）と `Space`／`Shift`（コレクティブ）も併用できます。

## 5. 燃料 150秒

- 燃料は **150秒**になりました（v3は90秒）。給油で+75秒（上限150秒）。
- シミュレーターモードではコレクティブが高いほど少し早く減りますが、フルコレクティブでも約136秒は持ちます。

## 6. 時間帯の選択

- スタート画面で**朝／昼／夕方／夜**を選べます。夜は街灯・窓明かり・航空障害灯が点き、夕方は太陽が低く赤くなります。
- ビルの窓は時間帯で光ります（夜は暖かい明かりがたくさん点灯）。飛行中も夕方へ向かって少しずつ暗くなっていきます。

## 7. 建物の破壊が段階的に

- 爆発の当たり方で壊れ方が変わります。**爆発の高さ**も考慮します（屋根の近くで爆発すると上部から崩れやすく、根元だと早く倒れます）。**とどめの一撃が大きいほど早く崩れます**。
- 崩壊中は 25%／50%／75% のタイミングで破片が落ち、最後は**瓦礫の山＋潰れた骨組み**が残ります。v3のように建物が急に消えることはありません。瓦礫の大きさは建物の高さに比例します。
- ダメージを受けた建物は、爆発の反対側へ傾きます。

## 8. 効果音（送ってもらった音声ファイル）

`heridehakai/sfx/` に入っています。音の特徴から判断して割り当てました。もし「この音は別の場面のものだ」と思ったら、**ファイルの中身を差し替えるだけ**で直せます（ファイル名がそのまま役割です）。

| ファイル | 元のファイル | 使われ方 | 判断の根拠 |
|---|---|---|---|
| `explosion-big.mp3` | `1.mp3` | 大爆発 | 3.4秒の低い爆発音（ピーク約70Hz） |
| `explosion.mp3` | `2.mp3` | 爆発 | 2.6秒の爆発音、少し短め |
| `gun.mp3` | `2-30d14f6d.mp3` | 機銃 | 鋭い破裂音を0.4秒に切り出し |
| `launch.mp3` | `2-30d14f6d.mp3` | ミサイル発射 | 同じ音の最初の0.9秒 |
| `warning.mp3` | `5.mp3` | 警告音 | 3.2秒の音程のあるアラーム（約560Hz） |
| `rotor.mp3` | `upload-16bd0c44.mp3` | ローター音（ループ） | 26.5秒の安定した低い唸り（69Hz） |
| `turbine.mp3` | `upload.mp3` | タービン音（ループ） | 11.5秒の安定した高い唸り（約740Hz） |

- 爆発音は距離で音量が変わります。戦闘機の通過音は戦闘機が近くを通るときに鳴ります。
- ローター／タービン音は飛行中の負荷で音量と音程が変わります。
- ファイルが欠けていても、従来の合成音に切り替わるので無音にはなりません。
- 設定 → サウンドの一番下に**試聴ボタン**（▶ 大爆発／爆発／銃声／…）を付けました。

## 既知の制限

- 外側の街のビルは中心ステージほど細部が作り込まれていません（屋根設備と瓦礫はありますが、看板・エアコン室外機などの細部は中心ステージのみ）。
- 敵機はプレイヤーの周囲±260〜300mまでしか追いません（無限に追うと戻れなくなるため）。
- 効果音の割り当ては音の特徴からの推測です。違和感があれば上の表を見てファイルを差し替えてください。

## 動作確認（v4）

- ヘッドレスブラウザで確認：タイトル画面（時間帯4種）、HUD（燃料150・コレクティブ・スロットル・RPM・対気速度）、全7ステージの読み込みと建物の重なりゼロ（8回チェック全て合格）、効果音ファイルの読み込み（404なし）、コンソールエラーゼロ。
- 飛行の確認：`Space`でコレクティブ55%→91%、前進で対気速度69〜71km/h、燃料150→148と減少。コレクティブを上げるとRPMが98%に下がる（ローター垂れ）ことも確認。
- 修正した不具合：時間帯カードを押すとステージが消える問題、ガソリンスタンド／料金所／隣接ビルの重なり。
