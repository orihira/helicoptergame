ヘリde破壊 クオリティアップ版 (v2)

【主な変更】
- 色空間バグ修正: r186で無効だった旧式指定(.encoding)11か所を修正。空・建物が本来の鮮やかな色に。光量とトーンマッピング(Neutral)を再調整
- ポストプロセス: HDRブルーム/MSAA/色収差/暖色寒色トーン/ビネット/被弾の赤フラッシュ/爆発の衝撃波ゆがみ
- FPSが落ちたら自動で品質ダウン。URLに ?fxq=0〜3 で固定(0=従来描画, 3=最高)
- 爆発・曳光弾・街灯・車のライト・航空障害灯・太陽をHDR発光化
- 背景: 円錐の山を、3層の稜線(空気遠近つき)に置き換え
- ゲーム感: 爆発のFOVキック、ヒットストップ、スコアポップアップ、5コンボごとの演出
- BGM: コンボと敵機の出現で激しくなる動的BGM (Mキーでミュート)
- UI: PCではタッチボタンを非表示(タッチすると出る)、HUDの質感、タイトルの説明を折りたたみ、リザルトの段階表示とスコアカウントアップ
- 元CSSの無効指定(.5rem.6rem のようなスペース抜け)を修正

【ファイル】index.html / game.js / three.min.js / config.js / ranking.js をそのまま公開フォルダへ置き換え
(HTTrack由来の不要ファイルは除いてあります)
